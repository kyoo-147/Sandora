project, then load only its profile and task-relevant references.

## Retrieval rules

- A request naming a project loads only that row's profile first.
- Cross-project work loads each affected profile, not every project.
- Source code, long documents, logs, completed plans, and web research remain
  cold context until the selected profile or task points to them.
- Add a project only when it has an accepted purpose, location or source, owner,
  and current status.
- Update `Last reviewed` in a profile when its facts are re-verified.
